[English Description]
Quad-Window Active Switcher & Aligner for Quad-Tasking.

This tool is a lightweight background utility that allows you to instantly switch and perfectly align up to 4 identical windows using a controller shortcut.
Upon launch, it completely automates the process by counting and targeting the most matching multiple windows (of a single auto-detected application) without any manual user setup.

Optimized for multi-account gameplay (MMORPGs) or heavy multitasking environments.
Except for the precise minimal outer borders used to indicate the active screen, there are no 1-pixel gaps, and zero input delay or lag exists.

Note: Fully compatible with Xbox controllers, as well as PS4/PS5 controllers.
      If the taskbar blinks red, execute 'Grid Align' to fix focus instantly.
      'Analog Bind' is a fix for physical hardware lag/faults. Keep it disabled(None) by default.

      If you counter any issues, please share the 'QuadSwitch.log' and 'QuadSwitch.json' files for analysis.

[Japanese Description]
4画面マルチアカウント・ウィンドウ切り替え支援ツール

本ツールは、コントローラーのボタン操作により、最大4つの同一ウィンドウ（起動時に自動選択された単一のアプリケーション/タイトル）を瞬時に切り替え、かつ正確に整列（アライメント）させるための常駐型ユーティリティです。
対象とするアプリケーションのタイトルは、複数起動しているウィンドウを対象に、自動的に選択されます。

オンラインゲームにおける複数アカウント（複垢）運用や、マルチタスク環境に最適化しています。
アクティブを示す枠線を表示する為の画面外枠以外は、隙間なく自動整列し、操作の引っかかりを少なくしています。

補足：PS4/PS5のコントローラー、およびXboxコントローラーに対応しています。
　　　タスクバーが赤点滅している場合は、'Grid Align'の実行で収まる可能性が高いです。
　　　'Analog Bind'はコントローラーの遅延・故障に対応する機能です。必要がなければ、無効(None)のままにしてください。

　　　問題が発生した場合は、解析用に'QuadSwitch.log'と'QuadSwitch.json'ファイルを添付して貰えると助かります。
